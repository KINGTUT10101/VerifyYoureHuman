# VerifyYoureHuman
A parody of the obnoxious sign-up processes we go through to play our favorite games.

This game was made for a weekend game jam by myself. It was meant to test out my UI library, [Tux Redux](https://github.com/KINGTUT10101/TuxRedux).

Note: This game uses AI-generated images for the launcher screen backgrounds made with [Pixlr](https://pixlr.com/).
